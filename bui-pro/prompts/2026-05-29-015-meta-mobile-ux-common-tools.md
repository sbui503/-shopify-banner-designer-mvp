Role: Meta AI UI/UX and visual QA partner.

Product: BUI Banner Pro, a mobile-friendly white-label cannabis label, sticker, packaging, and 3D preview design tool.

Design task: Improve the mobile UX so a novice can still use the core editor quickly, while a pro can access common actions without opening side panels.

Design direction:
- Keep desktop UX and visual language unchanged.
- On mobile, expose the most common selected-object actions in the main canvas area: copy, delete, lock/unlock, layer up/down, edit text, open layers.
- Use a compact bottom action rail, not a large modal.
- Use clear icons with short labels; no tutorial copy in the interface.
- When nothing is selected, the same space should switch to creation shortcuts: text, shape, upload, assets, 3D.
- Make delete visually distinct but not easy to hit by accident.
- Make lock state obvious, and make unlock accessible when an object is locked.
- Avoid overlapping the 2x enlarged mobile canvas, bottom footer, browser address bar, or side drawers.
- Ensure touch targets are at least about 44px tall, with horizontal scroll if needed.
- Preserve the dark production-tool style with green BUI accent.

Return UX recommendations and QA checklist only.
