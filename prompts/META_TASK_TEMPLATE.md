# Meta AI Task Prompt Template

Use this template for UI/UX, assets, research, browser/search review, and visual QA tasks.

Required fields:

- Task title
- User goal
- Current screen or file paths
- Screenshots or research links, if available
- Acceptance criteria
- Known constraints

Expected Meta AI output:

- UI/UX findings
- visual risks
- asset or copy recommendations
- source links for research claims
- exact files Codex should inspect
- next task
