# Qwen Task Prompt Template

Use this template for coding, repo scan, fixes, framework work, build failures, and test failures.

Required fields:

- Task title
- User goal
- Relevant file paths
- Failing command and compact output, if any
- Acceptance criteria
- Known constraints

Expected Qwen output:

- files to inspect
- proposed diff summary
- build/test commands
- risks or blockers
- next task
